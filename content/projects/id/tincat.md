### Nama Proyek

Situs TinCat

### Deskripsi Singkat

Halaman depan responsif yang dibuat sebagai proyek slicing untuk menirukan desain situs modern, menampilkan wadah yang mempertemukan para pencinta kucing dengan teman-teman berbulunya.

### Tujuan dan Latar Belakang

Proyek ini bertujuan mengasah kemampuan pengembangan front-end lewat praktik slicing secara langsung, dengan fokus pada ketepatan menirukan desain yang diberikan dan penerapan tata letak responsif. Proyek ini menjadi latihan untuk mematangkan kemampuan HTML, CSS, dan JavaScript dasar.

### Teknologi yang Digunakan

- **Frontend:**
  - HTML5 untuk struktur
  - CSS3 untuk penataan tampilan, termasuk Flexbox dan Grid untuk tata letak
  - JavaScript dasar untuk interaksi
- **Kontrol Versi:** Git dan GitHub untuk kolaborasi dan pengelolaan kode.

### Fitur Utama

- Desain sepenuhnya responsif dan dioptimalkan untuk desktop, tablet, maupun ponsel.
- Antarmuka yang menarik dan bersih sehingga mudah dijelajahi.
- Interaksi yang sederhana namun berfungsi, memakai JavaScript murni.
- Berfokus pada ketelitian slicing agar sesuai dengan mockup aslinya.

### Tantangan dan Solusi

- **Tantangan:** Mencapai ketepatan hingga tingkat piksel saat menerjemahkan desain.  
  **Solusi:** Memakai developer tools peramban dan alat ukur desain untuk memeriksa jarak, perataan, serta proporsi.

- **Tantangan:** Membuat tata letak tetap responsif di berbagai ukuran layar.  
  **Solusi:** Menerapkan pendekatan desain mobile-first.

### Hasil dan Dampak

- Meningkatkan kemahiran dalam teknik pengembangan front-end, khususnya slicing dan responsivitas.
- Menghasilkan halaman depan yang terlihat profesional sebagai bagian dari portofolio pribadi.
- Memperkuat pemahaman tentang praktik pengembangan web modern.
